🌐 ブログ連携（WordPress）

「気づき」タブで生成したブログ草稿を、WordPressに下書きとして直接投稿できます。投稿後は内容確認・本公開はWordPress側で行ってください（誤って即時公開されることはありません）。
ユーザー名・アプリケーションパスワードは、WordPress管理画面の「ユーザー」→「プロフィール」→「アプリケーションパスワード」から発行できます（通常のログインパスワードとは別物です）。

Google Cloud OAuth ID設定手順（初心者向け）

  1. Google Cloud Console にアクセスし、新しいプロジェクトを作成します。
  2. 「APIとサービス」のライブラリから「Google Calendar API」を検索し、有効化します。
  3. 「OAuth 同意画面」を設定し、公開ステータスを「テスト」にし、ご自身のテストユーザーメールアドレスを追加します。
  4. 「認証情報」から「認証情報を作成」をクリックし、「OAuth クライアント ID」を選択します。
  5. アプリケーションの種類に「ウェブ アプリケーション」を指定し、承認済みの JavaScript 生成元に現在の実行URL (例: http://localhost:8000) を登録します。
  6. 生成された「クライアント ID」を上の入力欄にコピー＆ペーストして「IDを保存」をクリックした後、「Google接続認証」ボタンを押して連携を完了させます。
